## Plugins Manager v1.01

🇮🇩 Rilis publik pertama — kelola plugin GoldHEN per game langsung dari PS4.
🇬🇧 First public release — manage GoldHEN plugins per game right on your PS4.

### ✨ Fitur / Features
- Daftar game terinstal + icon & CUSA yang punya plugin / Installed games with icon & CUSA
- Enable/Disable plugin (rename `.prx` ↔ `.prx.disable` + edit `plugins.ini` otomatis)
- Deteksi plugin baru otomatis / Auto-detect new plugins
- Install Plugins dari server + Fix Permission otomatis + Restart PS4
- Fix Permission, Uninstall Semua (plugins, plugins.ini & data plugin)
- Notifikasi update dari GitHub / GitHub update notifications
- Bahasa Indonesia & English

### 🔧 Perbaikan sejak build tes / Fixes since test build
- Pembacaan `plugins.ini` & judul game di PS4 asli / Reading `plugins.ini` & game titles on real hardware
- Pengaman: `plugins.ini` tidak pernah ditimpa jika gagal dibaca / Never overwrites an unreadable `plugins.ini`
- Status plugin lebih jelas / Clearer plugin status labels

### 📥 Install
Install `Plugins_Manager_v1.01.pkg` via Debug Package Installer / GoldHEN Package Installer. Requires HEN (GoldHEN 2.x recommended).
